# Speaker Spotlight

A responsive speaker showcase for Circle City Dev Night, built with React and Vite.
Speaker cards are rendered from the speaker data in `src/App.jsx`, with reusable
`SpeakerCard` and `TopicList` components in `src/components`.

## Getting started

Install dependencies and start the development server:

```sh
npm install
npm run dev
```

## Checks

```sh
npm run lint
npm run build
```
